# Lunarcore OS desktop app

Downloads for the Lunarcore OS desktop app. Get the newest version under **Releases**:

- **Mac:** the `.dmg` file. Open it, drag Lunarcore OS to Applications, then right-click the app and choose **Open** the first time.
- **Windows:** the `-setup.exe` file. If Windows says it protected your PC, click **More info**, then **Run anyway**.

Once installed, the app updates itself. You need a Lunarcore OS account to sign in.
